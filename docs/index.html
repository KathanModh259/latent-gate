LatentGate

Process Locally. Send Smart. Pay Less.

A VL-JEPA-inspired pipeline that compresses images, text, conversations, and RAG documents locally via Ollama, then sends only compact semantic payloads to any LLM API.

Quick Start

# Install
pip install latent-gate

# Pull Ollama models
ollama pull llava:7b
ollama pull llama3:8b

# Use it
python -m latent_gate photo.jpg "What is in this image?" --provider ollama

Features

Local-First

Vision and text compression runs on Ollama (free, no API key needed). Keep your data on your machine.

~80% Token Savings

Send ~200 tokens instead of ~1,200 for image queries. Massive cost reduction at scale.

Multi-Provider

OpenAI, Anthropic, Google, Groq, DeepSeek, Together, Azure, AWS Bedrock, Ollama, or any OpenAI-compatible endpoint.

MCP Server

Works with Claude Desktop, Cursor, Cline, Continue, Zed, and VS Code Copilot.

Video Processing

Selective decoding for video streams — only call API when scene changes (~2.85x fewer calls).

REST API

FastAPI server for web application integration with async support and streaming.
